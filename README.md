# 🌸 About Me - Styled Webpage

## 📌 Project Description

This project is a simple and attractive personal webpage created using HTML and CSS. It transforms a basic HTML page into a stylish webpage with a soft pink theme, clean layout, and beautiful design elements.

## ✨ Features

- Pastel pink background
- Attractive header section
- Navigation menu with About, Skills, and Contact links
- White content cards with rounded corners
- Box shadows for a modern look
- Interactive button with hover effect
- Responsive viewport for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```text
HTML-to-Styled-Webpage/
├── index.html
└── README.md
```

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. View and explore the styled webpage.
